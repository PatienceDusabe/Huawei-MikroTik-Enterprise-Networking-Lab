# Screenshot evidence checklist

Store sanitized screenshots under the corresponding subfolders:
- `vlans/`: Huawei VLAN membership; MikroTik Bridge → VLANs and Interfaces → VLAN
- `dhcp/`: MikroTik DHCP networks and leases, Windows `ipconfig`
- `firewall/`: NAT and Filter Rules with no secrets
- `testing/`: management ping, VLAN gateway ping, inter-VLAN test, internet connectivity, Wi-Fi client test

Remove serial numbers, passwords, public IP addresses and other identifying information before publishing.
